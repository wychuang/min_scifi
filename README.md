# 独研者工坊 MVP

一个面向独立研究者的单项目科研陪练原型。

它的目标不是承诺“改变世界”，而是把一个小研究从问题、假设、方法、文献、日志一路推到可讨论的预印本草稿。

## 当前范围

- 个人科研项目工作台
- 外部结构化资料库（Obsidian-like vault）
- 浏览器目录授权写入与可选本地后端路径模式
- Qwen Agent 系统设计草案
- 预注册表单
- 本地规则版范式检查
- 文献与研究日志
- 预印本写作骨架
- 每周复盘与可关闭的轻提示

## 运行方式

最轻量方式仍然是直接在浏览器打开 `index.html`。当前版本不需要构建步骤，表单草稿会保存在浏览器 `localStorage`。

如果要把项目写入外部文件夹，有两种方式：

1. 在 Chrome/Edge 中打开页面，点击“连接资料库目录”，选择一个资料库文件夹，再点击“写入资料库”。
2. 如需设置绝对路径，启动本地后端：

```powershell
python backend/server.py --vault D:\Research\min-scifi-vault --port 8765
```

然后打开 `http://localhost:8765/`。

如需启用 Qwen Agent，在启动后端前设置本地环境变量：

```powershell
$env:DASHSCOPE_API_KEY="你的本地密钥"
$env:MINSCIFI_QWEN_MODEL="qwen-plus"
$env:MINSCIFI_QWEN_APP_URL="https://dashscope.aliyuncs.com/apps/anthropic"
python backend/server.py --vault D:\Research\min-scifi-vault --port 8765
```

密钥只从后端环境变量读取，不写入浏览器、资料库或仓库。

推荐路径：

1. 打开 `index.html`
2. 点击右上角“填入示例”，先体验完整流程
3. 把示例内容替换成自己的研究项目
4. 在“外部资料库”里连接目录，或填写本地后端路径
5. 在“预注册表单”里写清楚假设、预期结果、否证条件、方法与数据
6. 查看“范式检查报告”的红黄绿信号
7. 在“文献与证据”里加入 DOI、arXiv ID、论文标题或搜索关键词
8. 在“研究日志”里记录每天推进、失败和下一步
9. 点击“生成骨架”，得到一份预印本写作结构
10. 点击“写入资料库”或“导出 JSON”备份当前项目

## 页面模块

### 项目概览

记录项目名称、研究问题、领域、目标日期和当前状态。左侧状态机用于提醒项目处于草稿、预注册、数据收集、分析、写作还是预印本阶段。

### 外部资料库

资料库写入一组普通文件，而不是把研究资料锁在前端里：

```text
project.json
README.md
preregistration/current.md
literature/items.json
literature/items.md
logs/daily.md
logs/weekly.md
writing/preprint-outline.md
sources/README.md
```

`sources/` 用于放 PDF、CSV、图片、实验记录、Zotero 导出等原始资料。应用只创建说明文件，不删除或改写未知文件。

### Qwen Agent 方向

下一阶段会把自然语言对话作为核心入口：用户先用普通语言讲研究想法，Agent 通过 Qwen 辅助澄清问题、生成结构化字段变更草案、标注依据，并让用户确认后再写入项目状态和资料库。设计详见 [`docs/qwen-agent-system.md`](docs/qwen-agent-system.md)。

当前实现已经提供基础对话入口和 `/api/agent/message` 后端接口：Agent 会返回回复、字段变更草案、依据、风险提示和下一步；现阶段只展示草案，不自动修改项目字段。

### 预注册表单

这是 MVP 的核心。用户需要在正式收集或解释数据前写下：

- 可证伪假设
- 预期结果
- 否证条件
- 方法与数据

这样做是为了减少“先看到结果，再倒推假设”的风险。

### 范式检查报告

当前版本使用本地规则生成 5 项检查：

- 可证伪性
- 方法完整度
- 资源现实性
- 红区预警
- 文献锚点

检查结果分为绿色、黄色、红色。绿色表示可以推进，黄色表示需要补强，红色表示建议先暂停扩写，把关键设计补完整。

### 文献与研究日志

文献区用于保存标题、DOI、arXiv ID 或检索关键词。日志区用于记录每天的实验、阅读、失败、疑问和下一步。

### 写作与复盘

“生成骨架”会根据当前项目内容生成一份预印本结构草稿。复盘区提供轻量提示，也可以打开“安静模式”关闭主动提示。

## 数据说明

- 浏览器 `localStorage` 只是草稿缓存和兜底模式
- 外部资料库是推荐的长期存储方式
- 换浏览器或清理浏览器数据会丢失未写入资料库的本地记录
- “导出 JSON”可以下载当前项目快照
- 当前版本没有账号、云同步、远程数据库或 LLM 调用
- 浏览器静态页不能直接写入用户手动输入的任意路径；绝对路径写入需要本地后端模式

## 产品边界

MVP 不做投资对接、专利代理、正式期刊投稿承诺，也不做全网抓取。它先验证一个核心假设：独立研究者是否愿意持续使用结构化科研陪练工具，把一个小研究推进到预印本。
