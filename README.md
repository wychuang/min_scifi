# 独研者工坊 MVP

一个面向独立研究者的单项目科研陪练原型。

它的目标不是承诺“改变世界”，而是把一个小研究从问题、假设、方法、文献、日志一路推到可讨论的预印本草稿。

## 当前范围

- 个人科研项目工作台
- 预注册表单
- 本地规则版范式检查
- 文献与研究日志
- 预印本写作骨架
- 每周复盘与可关闭的轻提示

## 运行方式

直接在浏览器打开 `index.html`。当前版本不需要后端和构建步骤，数据保存在浏览器 `localStorage`。

推荐路径：

1. 打开 `index.html`
2. 点击右上角“填入示例”，先体验完整流程
3. 把示例内容替换成自己的研究项目
4. 在“预注册表单”里写清楚假设、预期结果、否证条件、方法与数据
5. 查看“范式检查报告”的红黄绿信号
6. 在“文献与证据”里加入 DOI、arXiv ID、论文标题或搜索关键词
7. 在“研究日志”里记录每天推进、失败和下一步
8. 点击“生成骨架”，得到一份预印本写作结构
9. 每周填写复盘，决定下一周最小实验或最小写作动作
10. 点击“导出 JSON”备份当前项目

## 页面模块

### 项目概览

记录项目名称、研究问题、领域、目标日期和当前状态。左侧状态机用于提醒项目处于草稿、预注册、数据收集、分析、写作还是预印本阶段。

### 预注册表单

这是 MVP 的核心。用户需要在正式收集或解释数据前写下：

- 可证伪假设
- 预期结果
- 否证条件
- 方法与数据

这样做是为了减少“先看到结果，再倒推假设”的风险。

### 范式检查报告

当前版本使用本地规则生成 5 项检查：

- 可证伪性
- 方法完整度
- 资源现实性
- 红区预警
- 文献锚点

检查结果分为绿色、黄色、红色。绿色表示可以推进，黄色表示需要补强，红色表示建议先暂停扩写，把关键设计补完整。

### 文献与研究日志

文献区用于保存标题、DOI、arXiv ID 或检索关键词。日志区用于记录每天的实验、阅读、失败、疑问和下一步。

### 写作与复盘

“生成骨架”会根据当前项目内容生成一份预印本结构草稿。复盘区提供轻量提示，也可以打开“安静模式”关闭主动提示。

## 数据说明

- 数据保存在浏览器 `localStorage`
- 换浏览器或清理浏览器数据会丢失本地记录
- “导出 JSON”可以下载当前项目快照
- 当前版本没有账号、云同步、后端数据库或 LLM 调用

## 产品边界

MVP 不做投资对接、专利代理、正式期刊投稿承诺，也不做全网抓取。它先验证一个核心假设：独立研究者是否愿意持续使用结构化科研陪练工具，把一个小研究推进到预印本。
